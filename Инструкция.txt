Установка
---------
Запустите PADLOck-Setup-<версия>.exe и следуйте шагам установщика.
Нужны права администратора — программа ставится в C:\Program Files\PADLOck.
Ярлык появится в меню «Пуск».
Удаление — через «Параметры → Приложения» или ярлык «Удалить PADLOck».

Где что лежит
• Настройки прошивки и программы: %APPDATA%\PADLOck
• Журналы работы (по дням, хранятся 30 дней): %APPDATA%\PADLOck\logs
• APK FreeKiosk: скачивается вместе с обновлением программы в
  %APPDATA%\PADLOck\kiosk-release. Обновления — меню «Обновления».
Настройки сохраняются при обновлении и переустановке программы.


1. Подготовка планшета (новый или после сброса)
------------------------------------------------
1) Пройдите мастер первого запуска. НЕ входите в Google-аккаунт —
   нажмите «Пропустить». С аккаунтом прошивка не пройдёт.
2) Настройки → О планшете → 7 раз нажмите «Номер сборки».
3) Настройки → Система → Для разработчиков → включите «Отладка по USB».
4) Подключите планшет. На экране появится запрос «Разрешить отладку по USB?» —
   отметьте «Всегда разрешать» и нажмите «Разрешить».
5) FreeKiosk вручную НЕ открывайте — программа настроит его сама.

Если планшета нет в списке программы:
• проверьте кабель (некоторые кабели только заряжают);
• подтвердите запрос отладки на экране планшета;
• в Диспетчере устройств Windows планшет без драйвера отмечен жёлтым
  знаком — установите Google USB Driver или драйвер производителя.


2. Настройки прошивки
---------------------
Кнопка «Настройки прошивки» вверху. Разделы: Киоск, Wi-Fi, Регион и время,
Система, Мониторинг, Приложения. Нажмите «Сохранить».
Пароли (Wi-Fi, PIN, MQTT) хранятся зашифрованными средствами Windows —
прочитать их может только тот же пользователь на том же компьютере.
На другом компьютере их нужно будет ввести заново.

Про PIN
• Это PIN самого FreeKiosk, а не пароль экрана блокировки Android.
• Выход из киоска на планшете: 5 нажатий в правом нижнем углу, затем PIN.
• На новом планшете PIN из настроек станет PIN киоска.
• На уже настроенном планшете FreeKiosk примет изменения, только если PIN
  совпадает. Если FreeKiosk открывали вручную и PIN не меняли — там 1234.
• Держите один PIN на всех планшетах — иначе одной кнопкой их не обновить.


3. Прошивка
-----------
1) Подключите планшеты и отметьте их галочками в списке слева.
   Для нескольких планшетов — USB-хаб с отдельным питанием.
2) Нажмите «Прошить», проверьте галочки шагов и нажмите «Прошить».
3) Дождитесь окончания. Планшет перезагрузится и откроет киоск, после чего
   программа сама дождётся его загрузки и проверит. Статус «Проверено» —
   планшет готов. Если что-то не так, откроется таблица с ошибками.
Не отключайте кабель, пока идёт прошивка и проверка.
Кнопка «Прошить» во время любой операции становится «Стоп» — она прерывает
выполнение на всех планшетах.


4. Проверка
-----------
Кнопка «Проверка» — таблица по каждому планшету. Всё «OK» — планшет готов.


5. Изменить настройки на уже прошитых планшетах
------------------------------------------------
«Настройки прошивки» → измените нужное → «Сохранить и применить…».
Откроется окно шагов, изменённые пункты будут отмечены. Нажмите «Применить».
Кнопка «Прошить» тоже позволяет снять галочки и выполнить только нужные шаги.
Уже сделанное (та же версия FreeKiosk, удалённые приложения) проверяется
и пропускается.

Только сеть или только адрес страницы — кнопки «Изменить Wi-Fi» и
«Заменить URL» под кнопкой «Прошить».

Подробные инструкции по каждому шагу — кнопка «Инструкции» в программе.


6. Если что-то пошло не так
---------------------------
Первым делом смотрите журнал (кнопка «Папка логов») — там каждая команда
и её результат. Журнал можно отправить автору.

«Подтвердите отладку на экране»
    На планшете ждёт запрос отладки по USB — разрешите его.
«На планшете есть аккаунты»
    Удалите аккаунты: Настройки → Аккаунты. Или сбросьте планшет.
«Владелец устройства уже назначен»
    Планшет настроен другой программой. Нужен сброс к заводским настройкам.
«PIN не совпадает с PIN киоска на этом планшете»
    См. «Про PIN» выше.

Планшет не загружается (после ручного удаления пакетов в расширенном режиме)
    Если программа видит планшет — откройте командную строку (cmd) в папке
    программы и выполните:
        tools\adb shell "for p in $(pm list packages -u | cut -d: -f2); do cmd package install-existing $p >/dev/null; done"
        tools\adb reboot
    Если не видит — сброс через recovery: выключите планшет, зажмите
    Питание + Громкость вверх (или вниз), выберите «Wipe data/factory reset»,
    затем «Reboot system now». После сброса начните с пункта 1.


Сброс к заводским
-----------------
Отметьте планшеты галочками и нажмите «Сброс».
• Прошитый планшет FreeKiosk защищает от сброса — программа переведёт его
  в режим восстановления. На планшете: «Wipe data/factory reset» →
  подтвердить → «Reboot system now» (громкость — выбор, питание — ОК).
• Непрошитый планшет программа попробует сбросить сама.
Можно сбросить сразу несколько планшетов — они обрабатываются одновременно.
После сброса начните с пункта 1.


Расширенный режим
-----------------
Открывает таблицу всех пакетов с ручным удалением и отключением.
Нужен только для диагностики: удаление системных пакетов может сделать
планшет незагружаемым.
