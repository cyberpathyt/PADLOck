# Режим разработчика и отладка по USB

Компьютер управляет планшетом по кабелю через **отладку по USB**. Она спрятана в режиме разработчика, который включается один раз.

## Включить режим разработчика
1. Откройте **Настройки → О планшете**.
2. Найдите строку **Номер сборки** (внизу списка). Если её нет — загляните в **О планшете → Сведения о ПО**.
3. Нажмите на «Номер сборки» **7 раз подряд**. Появится подсказка «Вы стали разработчиком!».
4. Если планшет попросит PIN — значит, экран блокировки уже установлен; введите его.

## Включить отладку по USB
1. **Настройки → Система → Для разработчиков**.
2. Включите переключатель **Отладка по USB** и подтвердите «ОК».
3. Остальные пункты в этом меню не трогайте.

## Подключить к компьютеру
1. Подключите планшет кабелем к компьютеру с PADLOck.
2. На экране планшета появится окно **«Разрешить отладку по USB?»** с ключом компьютера.
3. Отметьте **«Всегда разрешать с этого компьютера»** и нажмите **«Разрешить»**.
4. В PADLOck планшет появится в списке со статусом «Готов к работе».

> Окно не появилось? Опустите шторку уведомлений и нажмите на уведомление «Отладка по USB», либо отключите и снова подключите кабель.
> Убедитесь что планшет подключен к порту с передачей данных, в AI TECLAST T60 к примеру 2 порта, один на передачу данных ближайший к картридеру, второй ТОЛЬКО на зарядку

! Если нажали «Отмена», статус в программе будет «Подтвердите отладку на экране». Переподключите кабель — окно появится снова.

## Режим подключения USB
Если планшет не виден, опустите шторку уведомлений → «Зарядка через USB» → выберите **Передача файлов**. Отладка работает в любом режиме, но некоторым кабелям и хабам так проще.
