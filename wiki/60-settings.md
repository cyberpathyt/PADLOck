# Настройки прошивки

Кнопка **Настройки прошивки** вверху. Настройки общие для всех планшетов и сохраняются на этом компьютере.

## Киоск
- **Папка с APK** — оставьте пустой: тогда прошивка идёт APK FreeKiosk, который пришёл с обновлением программы. Своя папка нужна только для проверки другой версии.
- **Что показывать** — сайт или приложение.
- **Адрес страницы** — например `https://kiosk.example.local`.
- **PIN** — PIN самого FreeKiosk (не экрана блокировки Android).
- **Кнопка «Назад»**, кнопка питания, строка состояния, заставка, яркость.

## Про PIN
- Выйти из киоска на планшете: **5 нажатий в правом нижнем углу**, затем PIN.
- На новом планшете PIN из настроек становится PIN киоска.
- На уже настроенном FreeKiosk примет изменения, только если PIN совпадает. Если FreeKiosk открывали вручную и PIN не меняли — там **1234**.
- Держите **один PIN на всех планшетах** — иначе одной кнопкой их не обновить.

## Wi-Fi
Имя сети, пароль, тип защиты и «забывать остальные сети». Проверка интернета отключается: планшет остаётся в сети без интернета.

## Регион и время
Часовой пояс, язык, NTP-сервер, время с этого компьютера. В сети без интернета время само не синхронизируется — укажите внутренний NTP-сервер, если он есть.

## Система
Без экрана блокировки; выключить геолокацию и фоновое сканирование.

## Мониторинг
Отправка состояния планшетов (батарея, память, Wi-Fi, адрес страницы) на MQTT-брокер: адрес сервера, порт, логин, пароль, интервал. Имя планшета в мониторинге — его имя в списке PADLOck.

## Приложения
Список пакетов на удаление (по одному на строку) и «Перезагружать планшет после прошивки».

! FreeKiosk, Настройки, лаунчер, клавиатура, WebView и системные компоненты не удаляются, даже если их вписать в список.

> Пароли (Wi-Fi, PIN, MQTT) хранятся зашифрованными средствами Windows. На другом компьютере или под другим пользователем их нужно ввести заново.
