# Расширенный режим

Кнопка **Расширенный режим** вверху открывает таблицу всех пакетов планшета: удалить, отключить, восстановить вручную.

! Нужен только для диагностики. Удаление системного пакета может сделать планшет незагружаемым. Для обычной работы хватает прошивки.

## Категории пакетов
- **Рекомендуется удалить** — видимые приложения, реклама, магазины.
- **Спорные** — удалять по ситуации.
- **Оставить** — нужны для работы.
- **Критичные** — отмечены замком, их удалить нельзя.
- **Нет данных** — пакет не описан в базах.

## Базы пакетов
Описания пакетов берутся из файлов `profiles\*.json` в папке программы и в `%APPDATA%\PADLOck\profiles`. Меню **Базы пакетов**: открыть папку своих баз, перечитать, сохранить пакеты без описания — чтобы дописать их в базу.

## Установка APK
Перетащите APK в область «Установка APK» — он установится на все отмеченные планшеты.
