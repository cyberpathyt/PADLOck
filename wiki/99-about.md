# О программе

PADLOck — подготовка Android-планшетов для режима киоска. Автор: vvedyaev.

## Где что лежит
- **Программа** — `C:\Program Files\PADLOck`.
- **Настройки прошивки и программы** — `%APPDATA%\PADLOck`.
- **Журналы** (по дням, хранятся 30 дней) — `%APPDATA%\PADLOck\logs`.
- **APK FreeKiosk из релиза** — `%APPDATA%\PADLOck\kiosk-release` (см. «Обновления»).
- **Свои базы пакетов** — `%APPDATA%\PADLOck\profiles`.

Настройки сохраняются при обновлении и переустановке программы.

## Свои страницы инструкций
Эти инструкции — обычные текстовые файлы `.md` в папке `wiki` программы. Свои страницы кладите в `%APPDATA%\PADLOck\wiki` (кнопка «Папка для своих страниц» слева внизу):
- файл с тем же именем заменяет страницу программы;
- новый файл добавляет страницу;
- порядок — по имени файла, поэтому имя начинается с номера, например `45-our-site.md`.

## Разметка страниц
- `# Заголовок` — заголовок страницы (первая такая строка — название во вкладке).
- `## Раздел` — подзаголовок.
- `- пункт` — список, `1. шаг` — нумерованный шаг.
- `> текст` — совет, `! текст` — внимание.
- `**жирный**`, обратные апострофы — команда или путь.
- `---` — разделительная линия.

> Горячие клавиши: Ctrl+F — поиск, Esc — закрыть окно.
