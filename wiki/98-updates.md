# Обновления

Программа сама проверяет обновления при каждом запуске и берёт их из релизов на GitHub. В каждом релизе лежат **установщик PADLOck** и **APK FreeKiosk** — ровно та версия, которой нужно прошивать планшеты.

## Как это выглядит
1. Через пару секунд после запуска программа проверяет релизы.
2. Если есть новая версия, открывается окно **«Обновление PADLOck»**: какая версия, что нового, прогресс скачивания в процентах и мегабайтах.
3. После скачивания файл проверяется по контрольной сумме SHA-256. Если файл повреждён или подменён, он не устанавливается.
4. Windows попросит подтвердить права администратора (программа стоит в Program Files).
5. Откроется окно установки с полосой прогресса, после чего PADLOck запустится сам.

Если обновление найдено во время прошивки, программа дождётся её окончания и только потом начнёт скачивание.

## FreeKiosk для прошивки
- APK FreeKiosk скачивается из того же релиза в `%APPDATA%\PADLOck\kiosk-release` — там всегда один файл.
- Прошивка идёт **только этим APK**. Какая версия в карточке «Прошивка под киоск» — та и ставится.
- Если в «Настройки прошивки → Киоск» указана своя папка с APK, берётся APK оттуда, а из релиза не скачивается.

## Меню «Обновления»
- **Проверить обновления** — проверить сейчас и сообщить результат.
- **Получать тестовые версии (dev)** — включать только тем, кто проверяет новые версии.
- **Страница релизов на GitHub** — список всех версий.

## Каналы stable и dev
- **stable** — рабочие версии, их получают все.
- **dev** — тестовые версии (на GitHub отмечены как Pre-release). Их получают только те, у кого включено «Получать тестовые версии».

> Отключили dev, а стоит тестовая версия новее рабочей — программа не откатывается назад и дождётся следующей рабочей версии.

## Если не обновляется
- **«нет связи с GitHub»** — компьютеру нужен доступ к github.com (и к objects.githubusercontent.com для скачивания).
- **«GitHub временно ограничил запросы»** — с одного адреса много проверок; через час пройдёт само.
- **Отменили запрос прав администратора** — программа повторит через 30 минут или сразу через «Проверить обновления».
- **Нет прав администратора** на компьютере — обновление ставит администратор, либо установщик с GitHub запускается вручную.
